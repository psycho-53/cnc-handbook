# CNC Handbook — v0.4

Русскоязычное веб-приложение-справочник для операторов и будущих программистов фрезерных станков с ЧПУ.

## Что работает

- Калькуляторы фрезерования, сверления, обратного расчёта и рабочего времени.
- 50 справочных статей: 24 исходные, 6 из руководств Siemens/FANUC и 20 расширенных по теории и технологии фрезерования. Каждая статья содержит краткую памятку и развёрнутую теорию.
- Поиск по названию, содержимому и терминам.
- Избранное, сохраняемое локально в браузере.
- Быстрая памятка G/M-кодов с раздельными разделами Haas, Fanuc (типовые ISO), Siemens 828D.
- Адаптивный интерфейс для телефона и компьютера.
- PWA-кеш: после первого успешного открытия по HTTPS основные материалы и калькуляторы работают офлайн.

## Открытие

Достаточно открыть `index.html` двойным щелчком. Для корректной проверки офлайн-режима и установки как приложения нужен `http://localhost` или HTTPS:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

## GitHub Pages

Репозиторий: `psycho-53/cnc-handbook`. В `Settings → Pages → Build and deployment → Deploy from a branch` выбери `main` и `/ (root)`. Адрес будет вида `https://psycho-53.github.io/cnc-handbook/`.

## Формулы

- Фреза: n = 1000·Vc/(π·D), Vf = n·z·fz, Q = ap·ae·Vf/1000.
- Сверло: n = 1000·Vc/(π·D), Vf = n·fn.
- Рабочее время: t = L/Vf.

Значения вводятся пользователем и **не являются рекомендованными режимами резания**. Производитель инструмента и станка, чертёж, безопасность и реальный техпроцесс имеют приоритет.

## Источники

Официальные ссылки на Sandvik Coromant, Haas Automation, Siemens приведены внутри сайта в разделе «Источники и ограничения» и у соответствующих статей.

## Технология

Статические HTML/CSS/JS, без фреймворков, трекеров, серверов, API и ИИ. Материалы находятся в `data.js`, `manuals.js` и `knowledge.js`; статьи можно редактировать без сервера. Избранное в `localStorage`.
